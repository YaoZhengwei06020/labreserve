# AI使用说明

本项目采用AI辅助进行需求与架构草案整理、Story拆分、代码及测试生成、文档完善和问题分析。AI输出作为候选材料，评审状态分别记录在ADR、业务规则审查和项目进度中。

验证结论来自实际执行的自动化测试，证据见[技术验证报告](verification.md)。团队决策、用户调研、实验A和真人可用性测试按实际开展情况记录，未开展的工作保持待完成。

本阶段工具：Codex Work，模型标识`gpt-6.1-sol`。此前规划阶段的模型版本待核实，未统一推定为同一版本。

规划参考BMAD阶段划分。BMAD工具安装与实际工作流执行分别记录，安装成功不等于已执行规划、评审或实验；状态见[工具配置](bmad-setup.md)。
