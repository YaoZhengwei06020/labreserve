# 课程交付要求

## 当前安排

- 按既定需求持续开发，不再安排临时需求变更。
- 实验B可不做；实验A暂按讲义保留。
- 截止日前提交GitHub链接，全部项目产物集中在同一仓库。
- 小组3–4人，课堂不需要汇报。
- 最终截止日期、附件要求与评分权重调整尚待课程通知明确。

## 过程材料

课程讲义要求架构至少5条ADR，每条说明备选方案及否决理由；根目录decision-log.md至少15条真实记录，其中至少5条否决或实质修改AI输出。正式日志在实际评审中形成，候选ADR不等同已发生的团队决策。

根目录sprint-status.yaml纳入版本控制，按真实状态变化持续更新并保留多次提交；根目录retrospective.md包含度量表、实验A结论与复盘。Story不得无证据从draft直接跳到done。

README应说明成员分工、使用的工具和模型版本，保留脱敏的关键会话或评审证据。原讲义要求的10分钟录屏是否随最新通知调整，仍待确认，不能直接由“课堂无需汇报”推定豁免。

实验A比较难度相当的两条Story：同一操作者、同一天、同一宿主与模型；实验组使用完整规划，对照组在独立会话中仅给需求；统一审查标准，报告样本量2和无随机化等局限。详见[实验计划](experiment-a/README.md)。
